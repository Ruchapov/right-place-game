## Доска

- Тянется под содержимое через 9-slice, а не растягиванием картинки целиком —
  иначе уголки и рама вытягиваются:
  `border-image: url(quest_board.webp) 160 fill / 40px stretch;`
  (срез 160 px картинки с каждой стороны, на экране — 40 css px).
- Ширина — экран минус 16 css px с каждой стороны. Высота — по содержимому.
- Листки отстоят от края доски на 22 css px.
- Сверху на доске, светлым по дереву: слева «Задания», справа
  «новые через Ч:ММ» (пока таймер не запущен — строки справа нет).

## Листок

- Тоже 9-slice: `border-image: url(quest_note.webp) 60 fill / 12px stretch;`
  плюс `filter: brightness(1.12)` — бумага чуть светлее исходника.
- Ширина — доска минус 44 css px. Высота — по тексту. Между листками 8 css px.
- Гвоздь: ширина 15 css px, центр на 82% ширины листка, верх гвоздя выше
  верхнего края листка на 30% высоты гвоздя. У каждого листка.
- Кинжал: только у АКТИВНОГО листка. Ширина 58 css px. Точка, где клинок
  входит в бумагу, — 91.5% ширины и 90.5% высоты картинки кинжала; ставится
  в точку листка (28, 40) css px от его левого верхнего угла. Рукоять уходит
  за край листка влево-вверх — так задумано.

## Текст — «написан чернилами»

- Шрифт: **Lora Italic** (Google Fonts, есть кириллица), подключать так же,
  как Cinzel (`<link>` в `index.html`). Cinzel тут не годится — в нём нет
  русских букв.
  - название: 17 px, Bold Italic;
  - описание: 14 px, Medium Italic, переносится на сколько угодно строк;
  - числа награды: 14 px, SemiBold Italic;
  - «Заменить»: 14 px, SemiBold Italic, подчёркнуто.
- Чернила: тёмные `#22160E`, красные `#78160C` (прогресс и «Заменить»).
- Эффект чернил: `mix-blend-mode: multiply` (текст впитывается в бумагу,
  видны волокна и пятна) и лёгкое `text-shadow: 0 0 1px` тем же цветом с
  прозрачностью ~0.35.
- Текст каждого листка чуть повёрнут: −1.2°, −0.7°, −1.5° по позиции
  листка (фиксированно, не случайно на каждый рендер — иначе дёргается).
- Отступы текста: слева 26 css px (у активного 48 — место под кинжал),
  справа 24.

## Строки листка

1. Название.
2. Описание (переносится).
3. Награда: число + иконка для золота, значков охотника, RP — по порядку.
   Справа в той же строке:
   - у активного — прогресс красными чернилами «N / M»;
   - у невзятого — «Заменить», только если замена на этом шаге ещё есть.
     Использовал замену — «Заменить» пропадает со ВСЕХ листков до
     следующего шага.
