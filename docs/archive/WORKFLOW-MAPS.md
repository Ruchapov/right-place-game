# Right Place — WORKFLOW создания карты

Дополняет главный WORKFLOW.md. Роли те же: чат = дизайн и генерация,
Claude Code = внесение файлов, Андрей = финальный визуальный судья.

## Золотой цикл карты
```
1. КОНЦЕПТ (1 фраза): "спуск к боссу", "две башни и мост".
   Согласовать ДО сетки.
2. КАРКАС: этажи + подъёмы из tools/map_tools.py (stairs, лестничная башня).
   Ничего руками — только проверенные функции.
3. ПРОВЕРКА: обе волны + линтер + debug(). Чинить по ASCII-отладчику.
   2 неудачные итерации подряд → элемент отлаживается на пустом поле отдельно.
4. СОБЫТИЯ: слоты hazard/reward/enemy по правилам скилла (комбо в узких местах,
   1 тайл чистоты). Снова обе волны — шипы меняют проходимость!
5. РЕНДЕР: полная карта + зумы подъёмов. Отдать Андрею.
6. ВИЗУАЛЬНЫЙ ТЕСТ Андрея: вопрос "как выбраться?" не должен возникать.
   Замечание → чинится ТОЛЬКО указанное место → снова п.3.
7. ПРИЁМКА: файл mapX.txt в репо + строка в пул + слоты в конфиг заполнителя.
```

## Жёсткие уроки (нарушение = переделка)
- Числа проверок НЕ отменяют глаз: трижды граф говорил "ок", глаз ловил
  нечитаемость. Проверки — необходимое условие, приёмка — только визуальная.
- Off-by-one в лестницах: игрок стоит на ряд ВЫШЕ верха столба. При любой
  странности стыковки — сначала печать зоны отладчиком, потом гипотезы.
- Не спамить неудачными попытками: если не сходится — отладка молча на
  пустом поле, показывать только рабочий результат.
- Одна правка за шаг. Вернуть "как было" — это тоже правка.

## Инструменты (tools/map_tools.py)
- make/fill/plat/save — примитивы сетки
- stairs(g, x_base, stand_from, stand_to, d, w=2) — зиккурат-лестница,
  ступени по 1 вверх, всё стоит на опоре
- build/wave — модель прыжка (вниз 5 / прямо 4 / вверх 1:3, 2:2, 3:запрещён)
- report(f, start) — обе волны с процентами
- lint(f) — ширина платформ ≥ 2
- debug(g, start) — ASCII: · ок, ▲ не вернуться, × не дойти

## Рендер-конвейер (render_lib.py)
render(gridfile, out, start, seed): фон 2 слоя (небо ×0.1, арки ×0.3,
анкер к земле) → силуэты за вуалью → вуаль → заливка тайлов текстурой +
обводка силуэта + кромка → геймплей из сетки → автодекор (свободные клетки,
зазор 1) → факелы на фасадах, цепи с потолков → игрок.
Опора объекта: верх платформы = y*T+38, верх тайла = y*T (surface_y).

## Definition of Done карты
Файл сетки + строка в пуле + слоты, обе волны 100%, линтер чист,
зумы подъёмов показаны, визуальное "ок" Андрея получено, изменение
закоммичено. Только после этого — следующая карта.
