# Висящий декор — 23.11.2026

Жалоба Андрея: «летают декорации в картах типа гробниц, где кресты и т.д.».

## Как искали (все 10 карт, текущие слои)

- `tools/find_floating_decor.py` — кусок декора (связная область пикселей в
  пустых клетках), ни один пиксель которого не ближе 2 px к опоре: полу, стене,
  потолку, кромке травы болота или бахроме платформы.
- Предметы над полом с щелью 3–64 px (под низом есть пол, сверху ничто не держит).
- Предметы, висящие больше чем наполовину над обрывом.
- Живое пламя свечей (`liveDecorManifest.ts`): есть ли под фитилём свеча в слое.
- Качающиеся стебли болота: стоит ли корень на полу.

куски стираются целиком, пламя без свечи снимается. Пересобрали слои — как и раньше,
снова `clean_trap_decor.py`.
