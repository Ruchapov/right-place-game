# Видеопамять забега: пары «до | после» (16.11.2026)

Раздел в документации — `docs/explore-engine.md`, «Видеопамять забега».
Слева всегда сборка ДО (полные листы), справа ПОСЛЕ (листы по размеру экрана,
упакованные кадры).

## `sheets/` — каждый упакованный лист, как его рисует GPU

Кадр (средний) нарисован так, как его рисует видеокарта в игре: билинейная
выборка без мипмапов, в масштабе экрана при DPR 2 (`масштаб отрисовки × 0.55 ×
2`). Слева — из полного оригинала (архив арта), справа — из нового файла по
раскладке манифеста `src/explore/sheetRes.ts`. Картинка увеличена вдвое
ближайшим соседом, чтобы видеть пиксели.

`pairs.json`, ключ `sheets`: 206 пар (кадр 0 и средний каждого листа),
**PSNR 27–40 дБ, медиана 33.5; средняя ошибка ≤ 5.5 из 255**. Разница — в
основном рябь «до» (большой лист, сжатый на GPU без мипмапов), которой «после»
нет; хуже всего — у навозника, искры парирования и у боссов на 0.5.

## `game/` — герой, враги и боссы в забеге

Офлайн-заглушка, одно зерно на обе сборки (одни и те же враги на тех же
местах), тикер остановлен на показе забега, кадр 0 текущей анимации, камера
на актёре. 390×844 и 844×390, DPR 2. Сценарий — `s41c_figures.mjs` в папке
автоплейтеста.

`pairs.json`, ключ `game`: 128 пар (герой, фехтовальщик, арбалетчик,
гробокопатель, кочегар, навозник, зверь, четыре босса; оба экрана), все в одной
анимации у обеих сборок: **размер спрайта и высота ног совпали до сотых
пикселя у всех 128**, по X — не больше 0.92 px (камера наведена на врага,
сдвинувшегося на долю пикселя между показом и остановкой). PSNR пар 23–40 дБ,
медиана 33.5.

⚠️ PSNR игровых пар — грубая мера: фон за полупиксельным сдвигом камеры даёт
большую попиксельную разницу. Качество самих листов — по `sheets/`; игровые
пары доказывают размер и посадку. Съёмка — с WebGL (первую, без него,
переснимали).
