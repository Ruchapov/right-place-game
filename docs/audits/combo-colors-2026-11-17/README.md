# Цвет удара на листе комбо (17.11.2026)

Кадры урона четырёх ударов комбо (17, 29, 35, 49) — «before» (исходный белый
росчерк) и «after» (перекраска по маске `Hero_Combo_slash.png` той же формулой,
что шейдер `entities/cloakTint.ts`), справа — кадр 6 листа `attack_<цвет>.png`
(обычный удар этого цвета) как эталон. Превью посчитано numpy по полным
оригиналам из архива; в игре то же делает шейдер при загрузке забега.

Формула: `v = max(r,g,b)`; `c = clamp(цвет × v / 0.886)`; при `v > 0.9` — к
белому до 45%; `out = mix(исходный, c, маска)`. Подобрана по листам
`attack_red/violet/gold.png`: средний цвет полос яркости росчерка совпал с
формулой до 3–10 единиц из 255.
